# BooleanNet Website

Source code for https://www.booleannet.com 

All pages have a source in Markdown format.

Add content via pull requests.

Uses [Quarto][quarto] to render the pages.

[quarto]: https://quarto.org/

# Local testing

Install Quarto.

```
pixi add quarto
```

Serve the website with:

```bash
make serve
```

Browse to <http://localhost:8000> to view the website.
